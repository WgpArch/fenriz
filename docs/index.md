# Fenriz — Darkbeauty Edition

A fast, minimal wlroots tiling compositor, riced with the Darkbeauty sapphire theme:
twelve clickable workspaces, glowing borders, soft shadows and rounded corners.

![Desktop](screenshots/shot-143535.png)

## Highlights

- **12 workspaces** — `workspaces = 12`, switched with `SUPER+1..0` and `SUPER+F1/F2`
- **Clickable Waybar pills** — ext-workspace-v1 with `ignore-hidden: false`
- **Darkbeauty theme** — sapphire `#2244dd` borders, glow shadows, 12 px rounding
- **Batteries included** — waybar bar, rofi launcher & powermenu, swaybg wallpaper, grim/satty screenshots
